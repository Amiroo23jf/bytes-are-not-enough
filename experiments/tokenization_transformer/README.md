# tokenization_transformer

Placeholder for the Theorem 3 experiment: compare a transformer trained on raw
Markov-k symbols versus a transformer trained on a tokenized version of the
same stream (BPE and LZW tokenizers), with the tokenized model's embedding /
LM head sized to the tokenizer vocabulary. Bit-per-Y-symbol curves are
compared against the same theoretical asymptote.

Not yet implemented.
